# iPhone 17 frame

`iphone-17-black-landscape.png` is the unmodified PNG from Apple's iPhone 17 product bezel package (Black, Landscape).

Source: https://developer.apple.com/design/resources/#product-bezels
Download: https://devimages-cdn.apple.com/design/resources/download/Bezel-iPhone-17.dmg

Copyright Apple Inc. Used under the Apple Design Resources license to present the Hold Up iPhone app. The image is not covered by any project-wide artwork license.

Original size: 2760 × 1350. Screen opening: x=69, y=72, width=2622, height=1206. Keep the frame's proportions and image intact; place the sign behind its transparent screen opening.

An embedded copy is used in the homepage project preview. Update both copies together.
